# 学习与开发路线

本文件描述建议顺序，不是自动执行全部阶段的授权。现状见 [STATUS](STATUS.md)，规则见 [DECISIONS](DECISIONS.md)，目标见 [VISION](../VISION.md)。

## 已完成：建造和双视图

先用色块实现了建造，现在升级为同一城镇的 2D/3D 视图。请先完成 [双视图练习](dual-view-guide.md)。
认识 Main、MapArea、2D 绘制、3D 相机和共用 UI，理解“状态只有一份，画面有两种”。
一次只完成一个可观察的小目标；不要要求用户先掌握所有场景树和三维坐标知识。

## 下一课：选中农田

点击已有农田改为选中，显示建筑信息；区分建造意图与选择意图。
选择对象由共享控制器持有，两个视图高亮同一目标。先不增加人口或生产系统。

## 随后：分工与实时经营

添加阮小二，使用按钮把他分配到选中的农田。阻止同一好汉同时在多个建筑工作。
再添加粮食和实时生产：游戏时间自动流动，已分配好汉的农田持续产粮。
由共同控制器推进一次模拟，2D/3D 均只显示结果，切换不得改变产量或重置生产进度。
之后再加入暂停/继续和进度显示，具体速度用可调整的临时数值。
没有“旬”或“下一旬”按钮，战斗回合不直接折算成经营时间。

## 地形与布局防守

未来加入高台、坡道、道路、固定敌军、聚义厅和箭楼。两种视图必须使用同一套高度、通行与伤害规则。
三维外观不能替代规则数据；当前地块有厚度不代表已实现坡道和高度。
战斗：指令阶段 → 自动执行与结算 → 下一回合。用同一敌军对比两种布局，观察可解释的结果差异。
内部 tick 只是实现细节。战斗期间是否继续生产仍待设计。

## 保存与分享

串起损伤、资源修复、保存；再做浏览器导出与其他平台验证。进攻战属于长期目标，先防守不等于取消进攻。
保留简单 2D 验证规则，逐步完善 3D 视觉；是否把 2D 打磨成正式战略视图另行确定。
