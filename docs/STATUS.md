## 已实现

- Godot 4.7.2 Standard，GDScript，Compatibility，960×600 视口。
- Main 拥有唯一 TownState，并将同一实例交给 2D 和 3D 视图。
- 16×12 格、左三列水面；2D 色块网格，3D 方块地面/农田小屋、固定斜俯视正交相机和灯光。
- 默认 3D，按钮切换 2D/3D；切换不改变资源和建筑，隐藏 3D 时停止该视口的持续渲染。
- 地图点击统一由 Main 处理：2D 坐标换格子，3D 射线拾取可见方块；两个视图不能重复消费同一点击。
- 初始 100 木材，农田花费 10；拒绝水面、重复、越界和资源不足。资源显示与重置为共用 UI。
- P02：Main 保存选中格子；点已有农田选择，点空地建造后自动选中；右栏信息面板显示名称/坐标/状态，“取消选择”按钮清除；2D 黄色描边、3D 屋顶上方半透明悬浮板高亮同一格，高亮不参与拾取；切换视图保留选择，重置清除选择。
