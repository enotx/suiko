## 已实现

- Godot 4.7.2 Standard，GDScript，Compatibility，960×600 视口。
- Main 拥有唯一 TownState，并将同一实例交给 2D 和 3D 视图。
- 16×12 格、左三列水面；2D 色块网格，3D 方块地面/农田小屋、固定斜俯视正交相机和灯光。
- 默认 3D，按钮切换 2D/3D；切换不改变资源和建筑，隐藏 3D 时停止该视口的持续渲染。
- 地图点击统一由 Main 处理：2D 坐标换格子，3D 射线拾取可见方块；两个视图不能重复消费同一点击。
- 初始 100 木材，农田花费 10；拒绝水面、重复、越界和资源不足。资源显示与重置为共用 UI。
- P02：Main 保存选中格子；点已有农田选择，点空地建造后自动选中；右栏信息面板显示名称/坐标/状态，“取消选择”按钮清除；2D 黄色描边、3D 屋顶上方半透明悬浮板高亮同一格，高亮不参与拾取；切换视图保留选择，重置清除选择。
- P03：唯一人物阮小二（`worker_cell`，INVALID_CELL=空闲）；`assign_worker` 调岗原子（验证通过才改动、失败保留旧工作）、`withdraw_worker`；选中农田面板显示“工作者”，未选中时显示阮小二去向；“分配阮小二/撤回阮小二”按钮按状态置灰；重置恢复空闲。
- P04：`grain` 与逐田 `farm_progress`；`advance_time` 是唯一模拟入口（长步多周期不丢产量）；Main `_process` 驱动、暂停时不传时间；暂停按钮、HUD 粮食、面板产出进度；重置清零。
- P05：`to_save_data`/`apply_save_data` 显式编码坐标/进度并带版本与逐项校验（校验全过才替换状态）；Main 做 JSON 文件 IO；右栏“保存城镇/读取存档”按钮；损坏/旧版/缺失均提示且不破坏当前经营。
- P06.a：云端三层验证体系——无头回归、Xvfb 真实渲染截图、noVNC 浏览器远程桌面（`scripts/cloud-dev.sh`）；Web 非线程导出与 `suiko-web` 静态服务（`172.17.0.1:8090`，systemd 常驻）。
